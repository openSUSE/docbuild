# Contributing to Docbuild

First off, thank you for considering contributing to `docbuild`! It's people like you that make open source such a great community. 

To ensure the project remains sustainable and our maintainers don't burn out, we have a few guidelines.

**Please read this document before opening a Pull Request.**

## 🤝 How we work together

We love helping people learn about open source, Python, and Git. However, reviewing code and fixing broken builds takes significant time. 

Please be prepared to work through review comments with us. If your availability changes and you're unable to see the PR through, just leave a comment on the thread so the community can take over.

To keep the project stable and maintainable, all pull requests must include tests, pass CI checks, and address review feedback. Inactive or abandoned PRs will be closed to keep the backlog focused.

## 🛠️ Development & Submission Guide

To keep our documentation DRY (Don't Repeat Yourself) and maintain a single source of truth, we keep all our detailed instructions in the Developer Guide rather than this file.

Please refer to the **[Docbuild Developer Guide](https://opensuse.github.io/docbuild/latest/developer/)** for detailed instructions on:

* Setting up your local development environment
* Formatting code with Ruff
* Running the test suite
* Adding changelog entries [(news fragments)](https://opensuse.github.io/docbuild/latest/developer/add-newsfragments.html)
* Submitting Pull Requests
