Fixed ``docbuild check files`` for translations and cross-references. References are now resolved to their target deliverable, so the repository and DC file come from the target. Translations are checked against their locale's branch and subdir, and missing translations are reported as skipped instead of as errors. Empty ``<locale>`` elements no longer cause an error. The output is now a tree per product, docset, and language with a status icon for each DC file, and it is no longer mixed with log messages.
