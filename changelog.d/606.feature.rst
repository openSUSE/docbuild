Added a ``files_from`` option to ``RsyncOptions``. When it is set, ``rsync()`` passes ``--files-from <file>`` to rsync, so only the paths listed in the file are transferred. In archive mode it also passes ``-r``, because rsync turns off the recursion implied by ``-a`` when a file list is used. The paths are relative to the source, and the file is not read or validated by ``rsync()``.
