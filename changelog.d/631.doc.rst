The configuration documentation is now split into a concept section and a task section. It explains where docbuild searches for application and environment configuration files, how multiple files are merged, and how the ``--app-config`` and ``--env-config`` options change the search. It also documents the XDG environment variables that change the per-user directories on Linux and macOS, and the ``--flat`` and ``--validate`` options of :command:`docbuild config list`.
