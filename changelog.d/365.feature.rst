Added automatic generation of ``llms.txt`` and clean Markdown files during the HTML build process to support AI bots. This feature can be configured via the new ``build.build_llmstxt`` and ``paths.llmstxt_dir`` options in ``env.toml``. The generator strips navigation and layout elements using a custom parser, converts the core content using ``justhtml``, and safely injects ``<link rel="alternate" type="text/markdown">`` tags into the source HTML headers.
