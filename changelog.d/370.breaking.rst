Refactored the environment configuration to remove obsolete server terminology. The ``[server]`` section has been removed (along with unused ``host`` and ``port`` keys), and its remaining keys were moved to a new ``[general]`` section. Additionally, ``[xslt-params]`` was restructured into ``[xslt.common]``, ``[xslt.html]``, and ``[xslt.pdf]`` to allow target-specific parameter configurations.
